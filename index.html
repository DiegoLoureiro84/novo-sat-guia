Guia Coplan no Novo SAT

Ajuda por tela e roteiros guiados rodando por cima das telas GeneXus já existentes.

SEFAZ Salvador · Novo SAT Prova de conceito · aguardando validação técnica v0.1 · 28/09/2026

Uma camada de JavaScript que mostra, na própria tela do sistema, o que preencher e em que ordem. Ela espera o usuário executar cada ação e abre o manual da tela certa. No GeneXus, a mudança é incluir arquivos na Master Page. Nenhuma transação, web panel ou regra de negócio é alterada.

1evento alterado no GeneXus (Master Page, Start)
0transações ou web panels modificados
1 diaestimado para a prova de conceito
3fluxos no piloto, não os 12 macroprocessos

Por que entra na capacitação

O contrato prevê 368h de passagem de conhecimento em janeiro de 2027, com avaliação ao final de cada módulo e repetição sem ônus quando o resultado não é satisfatório. A prática guiada em laboratório é a maior parte de cada dia de aula. O Guia Coplan atua nessa etapa e continua disponível depois que o instrutor vai embora.

Três camadas da proposta

A · Evidência de aceite

Presença, avaliações, certificados e relatório por módulo em fluxo digital. O Guia registra quem concluiu cada roteiro, o que vira evidência prática.

Fora do GeneXus
B · Manual por tela

Manual Operacional web, organizado pelos 12 macroprocessos. O botão de ajuda abre a página do manual da tela aberta.

Conteúdo fora do GeneXus
C · Roteiro guiado

Passo a passo sobre a tela real, que só avança quando o usuário faz a ação. Piloto em 3 fluxos de alto volume.

Detalhado neste documento
Para quem é este documento: para a equipe GeneXus avaliar se a abordagem é viável no Novo SAT, antes de qualquer compromisso com o cliente. O menu lateral segue a ordem de leitura sugerida.

Implementação

Como funciona

O que roda onde, e por que o GeneXus quase não muda.

Por que não mexe no GeneXus
  • O GeneXus gera HTML comum. O script só lê esse HTML depois que a página carrega.
  • O alvo de cada passo é um seletor CSS, normalmente o id que o GeneXus já gera para o controle.
  • Os eventos são ouvidos no document, então continuam funcionando quando o GeneXus redesenha um trecho da tela via AJAX.
  • O Driver.js espera até 4 segundos o controle aparecer (waitForElement), o que cobre telas que carregam por partes.
Quem mantém o quê
  • Dev GeneXus: inclui os scripts na Master Page uma vez e evita renomear controles que têm roteiro.
  • Inovação: mantém o motor guia-coplan.js e o visual.
  • Analistas e instrutores: escrevem os JSON dos roteiros e o manual. Não precisam compilar a KB.
  • Roteiro novo ou texto corrigido não exige build GeneXus, só publicar o JSON.
Implementação

Passo a passo no GeneXus

Prova de conceito em 1 dia, numa KB de desenvolvimento.

Os pontos marcados com validar são exatamente o que a prova de conceito precisa responder.

  1. Copiar a pasta do kit para a aplicação publicada

    Copie a pasta guia-coplan/ (estrutura em Código) para o diretório web onde a aplicação serve arquivos estáticos, de forma que <url-da-aplicação>/guia-coplan/guia-coplan.js abra no navegador.

    validar o diretório exato depende do gerador (Java ou .NET) e do deploy do ambiente. A pasta precisa entrar no pacote de homologação e produção.

  2. Incluir os scripts no evento Start da Master Page

    Usar Form.JScriptSrc.Add() para os scripts e Form.HeaderRawHTML para as folhas de estilo. Use caminho a partir da raiz do servidor, porque em Java a URL da tela fica dentro de /servlet/ e um caminho relativo resolveria errado.

    validar se os arquivos incluídos na Master Page aparecem em todas as telas que a usam. Se o JScriptSrc não resolver o caminho, a alternativa comentada no código inclui as tags <script> pelo HeaderRawHTML.

  3. Confirmar que o Guia enxerga a tela

    Abra uma tela, abra o console (F12) e execute:

    GuiaCoplan.telaAtual()   // deve retornar o nome do objeto, ex.: "wpparcelamentosimulacao"

    validar o formato da URL no ambiente. O motor trata /objeto.aspx (.NET) e /servlet/com.pacote.objeto (Java). Se for diferente, ajusta-se uma função.

  4. Mapear os controles com Alt+clique

    No console, ative o modo mapeamento e recarregue a página:

    localStorage.guiaCoplanMapear = '1'

    Com Alt+clique em qualquer campo, o seletor aparece na tela e é copiado. Em geral é o id gerado pelo GeneXus (variável com prefixo v, linha de grid com sufixo _0001).

    validar se esses IDs são estáveis entre builds. Eles derivam do nome do controle, então só devem mudar se o controle for renomeado ou estiver dentro de Web Component com prefixo variável.

  5. Escrever o roteiro da tela em JSON

    Crie guia-coplan/roteiros/<nome-da-tela>.json. Cada passo tem alvo, titulo, texto e, se quiser travar o avanço, esperar do tipo preenchido, marcado ou clique.

  6. Testar um passo que dispara evento no servidor

    Use "esperar": {"tipo":"clique"} num botão com evento GeneXus. Depois de cada build, rode no console:

    GuiaCoplan.verificar()   // tabela com cada passo e se o alvo foi encontrado

    validar se o evento roda por AJAX (o roteiro segue) ou recarrega a página inteira (o roteiro fecha). No segundo caso, o piloto evita esse fluxo ou a v0.2 passa a retomar o roteiro após o recarregamento.

Motor guia-coplan/guia-coplan.js 
/*!
 * Guia Coplan v0.1 (prova de conceito)
 * Roteiros guiados e ajuda por tela para aplicações web GeneXus.
 * Não altera nenhum objeto GeneXus: só lê a página já renderizada.
 * Depende de Driver.js 1.8.0 (licença MIT), carregado antes deste arquivo.
 */
(function (w, d) {
  'use strict';

  var CFG = {};
  var roteiroAtual = null;
  var telaCarregada = null;
  var driverObj = null;
  var botao = null;
  var passoOk = {};          // índice do passo -> ação exigida já foi feita
  var observador = null;

  var PADRAO = {
    roteirosUrl: 'guia-coplan/roteiros/', // pasta com um JSON por tela
    roteiros: null,          // alternativa: objeto { "nome-da-tela": {roteiro} } já embutido
    manualUrl: null,         // ex.: 'https://manual.exemplo/novo-sat/#{tela}'
    tela: null,              // força o nome da tela (senão é deduzido da URL)
    montarBotaoEm: null,     // seletor onde o botão ? é inserido; vazio = botão flutuante
    registrar: null,         // function (evento) {...} para guardar evidência de uso
    onAbrirManual: null,     // function (url, roteiro) {...}; padrão abre nova aba
    debug: false
  };

  /* ---------- utilitários ---------- */
  function log() { if (CFG.debug && w.console) console.log.apply(console, ['[guia-coplan]'].concat([].slice.call(arguments))); }
  function q(sel) { try { return sel ? d.querySelector(sel) : null; } catch (e) { return null; } }
  function qa(sel) { try { return sel ? d.querySelectorAll(sel) : []; } catch (e) { return []; } }
  function el(tag, cls, html) { var e = d.createElement(tag); if (cls) e.className = cls; if (html != null) e.innerHTML = html; return e; }

  function registrar(evento, extra) {
    var dados = { evento: evento, tela: telaCarregada, roteiro: roteiroAtual && roteiroAtual.titulo, quando: new Date().toISOString() };
    for (var k in (extra || {})) dados[k] = extra[k];
    log(dados);
    if (typeof CFG.registrar === 'function') { try { CFG.registrar(dados); } catch (e) {} }
  }

  /* Deduz o nome do objeto GeneXus pela URL.
     .NET:  /novosat/wpparcelamento.aspx            -> wpparcelamento
     Java:  /novosat/servlet/com.novosat.wpparcelamento -> wpparcelamento
     Validar com as URLs reais do ambiente. */
  function telaAtual() {
    if (CFG.tela) return String(CFG.tela).toLowerCase();
    var ult = (w.location.pathname.split('/').pop() || '').replace(/\.(aspx|html?)$/i, '');
    return ult.split('.').pop().toLowerCase();
  }

  function carregarRoteiro(tela) {
    if (CFG.roteiros) return Promise.resolve(CFG.roteiros[tela] || null);
    return fetch(CFG.roteirosUrl + tela + '.json', { cache: 'no-cache', credentials: 'same-origin' })
      .then(function (r) { return r.ok ? r.json() : null; })
      .catch(function () { return null; });
  }

  /* ---------- condição de "esperar" ---------- */
  // tipos: "clique" | "preenchido" | "marcado"
  function condicaoAtendida(p, i) {
    var e = p.esperar;
    if (!e) return true;
    if (e.tipo === 'clique') return !!passoOk[i];
    var alvo = e.alvo || p.alvo;
    var itens = qa(alvo);
    for (var k = 0; k < itens.length; k++) {
      if (e.tipo === 'marcado' && itens[k].checked) return true;
      if (e.tipo === 'preenchido' && String(itens[k].value || '').trim() !== '') return true;
    }
    return false;
  }

  function atualizarPopover() {
    if (!driverObj || !driverObj.isActive() || !roteiroAtual) return;
    var i = driverObj.getActiveIndex();
    var p = roteiroAtual.passos[i];
    var pop = driverObj.getState('popover');
    if (!p || !pop) return;
    var ok = condicaoAtendida(p, i);
    pop.nextButton.disabled = !ok;
    pop.nextButton.classList.toggle('guia-desabilitado', !ok);
    var aviso = pop.description.querySelector('.guia-aviso');
    if (!ok && !aviso && p.esperar) {
      pop.description.appendChild(el('span', 'guia-aviso', p.esperar.mensagem || 'Execute a ação indicada para continuar.'));
    } else if (ok && aviso) {
      aviso.remove();
    }
  }

  // Delegação no document: sobrevive aos re-renders que o GeneXus faz via AJAX.
  function ouvirAcoes(ev) {
    if (!driverObj || !driverObj.isActive() || !roteiroAtual) return;
    var i = driverObj.getActiveIndex();
    var p = roteiroAtual.passos[i];
    if (!p || !p.esperar) return;
    var alvo = p.esperar.alvo || p.alvo;
    var casou = false;
    try { casou = !!(ev.target.closest && ev.target.closest(alvo)); } catch (e) {}
    if (!casou) return;
    if (p.esperar.tipo === 'clique' && ev.type === 'click') {
      passoOk[i] = true;
      registrar('acao_executada', { passo: i + 1 });
      // dá tempo para o evento GeneXus rodar e a tela se atualizar
      setTimeout(function () { if (driverObj && driverObj.getActiveIndex() === i) driverObj.moveNext(); }, 600);
      return;
    }
    if (!passoOk[i] && condicaoAtendida(p, i)) { passoOk[i] = true; registrar('acao_executada', { passo: i + 1 }); }
    atualizarPopover();
  }

  /* ---------- roteiro ---------- */
  function iniciarRoteiro() {
    if (!roteiroAtual) return;
    var criar = w.driver && w.driver.js && w.driver.js.driver;
    if (!criar) { console.error('[guia-coplan] Driver.js não foi carregado antes do guia-coplan.js'); return; }
    passoOk = {};
    var total = roteiroAtual.passos.length;
    driverObj = criar({
      showProgress: true,
      progressText: 'Passo {{current}} de {{total}}',
      nextBtnText: 'Próximo',
      prevBtnText: 'Voltar',
      doneBtnText: 'Concluir',
      popoverClass: 'guia-coplan-popover',
      overlayOpacity: 0.55,
      stageRadius: 12,
      waitForElement: 4000,        // espera o GeneXus desenhar o controle (AJAX)
      allowClose: true,
      steps: roteiroAtual.passos.map(function (p) {
        return {
          element: p.alvo || undefined,
          popover: { title: p.titulo, description: p.texto, side: p.lado || 'bottom', align: 'start' }
        };
      }),
      onPopoverRender: function () { setTimeout(atualizarPopover, 0); },
      onNextClick: function () {
        var i = driverObj.getActiveIndex();
        if (!condicaoAtendida(roteiroAtual.passos[i], i)) { atualizarPopover(); return; }
        registrar('passo_concluido', { passo: i + 1 });
        if (i === total - 1) { registrar('roteiro_concluido', { passos: total }); driverObj.destroy(); }
        else driverObj.moveNext();
      },
      onCloseClick: function () {
        registrar('roteiro_interrompido', { passo: driverObj.getActiveIndex() + 1 });
        driverObj.destroy();
      }
    });
    registrar('roteiro_iniciado', { passos: total });
    driverObj.drive();
  }

  function abrirManual() {
    var url = CFG.manualUrl ? CFG.manualUrl.replace('{tela}', encodeURIComponent((roteiroAtual && roteiroAtual.manual) || telaCarregada)) : null;
    registrar('manual_aberto');
    if (typeof CFG.onAbrirManual === 'function') return CFG.onAbrirManual(url, roteiroAtual);
    if (url) w.open(url, '_blank', 'noopener');
  }

  function montarBotao() {
    if (botao) { botao.remove(); botao = null; }

  }

  /* ---------- ferramentas para o desenvolvedor ---------- */
  function seletorDe(no) {
    if (!no || no === d.body) return 'body';
    if (no.id) return '#' + (w.CSS && CSS.escape ? CSS.escape(no.id) : no.id);
    var caminho = [];
    while (no && no.nodeType === 1 && no !== d.body) {
      if (no.id) { caminho.unshift('#' + (w.CSS && CSS.escape ? CSS.escape(no.id) : no.id)); break; }
      var tag = no.tagName.toLowerCase(), pai = no.parentNode, idx = 1, irm = no;
      while ((irm = irm.previousElementSibling)) if (irm.tagName === no.tagName) idx++;
      caminho.unshift(tag + ':nth-of-type(' + idx + ')');
      no = pai;
    }
    return caminho.join(' > ');
  }

  // Alt+clique em qualquer controle mostra o seletor para usar no JSON.
  function mapear() {
    d.addEventListener('click', function (ev) {
      if (!ev.altKey) return;
      ev.preventDefault(); ev.stopPropagation();
      var s = seletorDe(ev.target);
      console.log('[guia-coplan] seletor:', s, ev.target);
      if (navigator.clipboard) navigator.clipboard.writeText(s).catch(function () {});
      var t = el('div', 'guia-coplan__toast', 'Seletor: <code></code>');
      t.querySelector('code').textContent = s;
      d.body.appendChild(t);
      setTimeout(function () { t.remove(); }, 3500);
    }, true);
    console.log('[guia-coplan] modo mapeamento ativo: Alt+clique em um controle.');
  }

  // Lista quais alvos do roteiro atual não existem na tela (use após cada build).
  function verificar() {
    if (!roteiroAtual) { console.warn('[guia-coplan] nenhuma tela com roteiro carregada'); return []; }
    var r = roteiroAtual.passos.map(function (p, i) {
      return { passo: i + 1, alvo: p.alvo || '(centro da tela)', encontrado: p.alvo ? !!q(p.alvo) : true };
    });
    if (console.table) console.table(r);
    return r;
  }

  /* ---------- ciclo de vida ---------- */
  function carregarTela() {
    var tela = telaAtual();
    if (tela === telaCarregada) return;
    telaCarregada = tela;
    carregarRoteiro(tela).then(function (r) {
      roteiroAtual = r && r.passos && r.passos.length ? r : null;
      log('tela', tela, roteiroAtual ? 'com roteiro' : 'sem roteiro');
      montarBotao();
    });
  }

  function iniciar(config) {
    CFG = {};
    for (var k in PADRAO) CFG[k] = PADRAO[k];
    var ext = config || w.GUIA_COPLAN_CONFIG || {};
    for (var j in ext) CFG[j] = ext[j];

    d.addEventListener('click', ouvirAcoes, true);
    d.addEventListener('change', ouvirAcoes, true);
    d.addEventListener('input', ouvirAcoes, true);

    // Reposiciona o destaque quando o GeneXus atualiza a tela via AJAX.
    if (w.MutationObserver && !observador) {
      var t = null;
      observador = new MutationObserver(function () {
        clearTimeout(t);
        t = setTimeout(function () { if (driverObj && driverObj.isActive()) { driverObj.refresh(); atualizarPopover(); } }, 150);
      });
      observador.observe(d.body, { childList: true, subtree: true });
    }

    // Web User Experience "Smooth" pode trocar de tela sem recarregar a página.
    setInterval(carregarTela, 1000);
    try { if (w.localStorage && localStorage.getItem('guiaCoplanMapear') === '1') mapear(); } catch (e) {}
    carregarTela();
  }

  w.GuiaCoplan = { iniciar: iniciar, iniciarRoteiro: iniciarRoteiro, mapear: mapear, verificar: verificar, telaAtual: telaAtual };

  if (w.GUIA_COPLAN_CONFIG && w.GUIA_COPLAN_CONFIG.autoIniciar !== false) {
    if (d.readyState === 'loading') d.addEventListener('DOMContentLoaded', function () { iniciar(); });
    else iniciar();
  }
})(window, document);

Riscos e perguntas

Limites da abordagem e o que a equipe GeneXus precisa responder.

Limites e riscos
  • Telas ainda em desenvolvimento. Roteiro só em telas estáveis. Por isso o piloto é de 3 fluxos.
  • Controle renomeado quebra o passo. A tela não trava: o Driver.js mostra o texto no centro. Rodar verificar() após cada build pega isso antes do usuário.
  • O roteiro orienta, não valida regra de negócio. A validação continua no GeneXus.
  • Registrar eventos envolve dados de uso de servidores. Se for ligado, tratar com o cliente e a LGPD antes.
Perguntas para a equipe GeneXus
  1. O Novo SAT é gerado em Java ou .NET, e qual é o formato real das URLs?
  2. Todas as telas usam a mesma Master Page?
  3. Os fluxos candidatos ao piloto (Atendimento, Parcelamento, NFS-e) rodam eventos por AJAX?
  4. Há Web Components aninhados nessas telas? Eles mudam o prefixo dos IDs.
  5. Quem pode dedicar 1 dia para esta prova de conceito, e em qual KB?
