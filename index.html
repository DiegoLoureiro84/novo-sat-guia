Guia Coplan v1.2

Passo a passo guiado e manual de cada tela, por cima das telas GeneXus que já existem, sem refazer nenhuma tela.

Validado no GeneXus 16 (KB do Tributário) v1.2 · base automática + 4 opcionais Novo SAT (GeneXus 17/18): a validar

Este site é o manual do desenvolvedor. A base é a única parte obrigatória e não exige que ninguém escreva nada: instalada na Master Page, ela dá a todas as telas um passo a passo e um manual gerados da própria tela. Escrever textos é opcional, para quem quiser melhorar telas específicas, e tem duas formas de guardar: pasta ou tabela.

Teste feito por Bruno Marchetto na KB do Tributário, tela de emissão de NFS-e.

Funcionou

A pergunta era se uma camada JavaScript conseguia guiar o usuário numa tela GeneXus real sem mexer nos objetos. No GeneXus 16 a resposta foi sim. O Bruno adaptou o motor em pontos que só aparecem numa tela de verdade; esses ajustes estão todos na v1.2. O passo a passo e o manual automáticos da v1.2 ainda não foram testados na KB.

Ajustes do Bruno no motor (mantidos na v1.2)

Select2

O dropdown do Select2 ficava atrás do escurecimento do guia. O CSS passou a liberar o dropdown aberto e as opções.

Lupa de consulta

Campo e lupa são destacados juntos. Com o popup de consulta aberto, o guia pausa e volta quando ele fecha.

Campos ocultos

Passo cujo campo está escondido é pulado, para frente e para trás.

Controle recriado e posição

Quando o GeneXus recria o controle, o guia destaca o novo. O balão se reposiciona se a tela rolar ou mudar.

Combinações prontas

A · Só a base

Todas as telas com passo a passo e manual automáticos. Nenhum texto escrito.

  • Implantar: ½ a 1 dia
  • Manter: nenhuma rotina
  • Bom para: começar já, cobrir todo o sistema
  • Limite: textos genéricos, sem regras de negócio
B · Base + pasta

Automático em tudo e textos escritos nas telas mais usadas.

  • Implantar: 1 dia + escrita por tela
  • Manter: verificar telas escritas após atualização
  • Bom para: poucas telas escritas, deploy fácil
  • Limite: publicar depende do servidor
C · Base + tabela

Automático em tudo e textos escritos publicados pelo cadastro.

  • Implantar: 3 a 5 dias + escrita por tela
  • Manter: verificar telas escritas; cadastro restrito
  • Bom para: muitas telas, textos ajustados toda semana (ex.: no treinamento)
  • Limite: mais objetos para criar e compilar
+ Evidência

Soma a qualquer combinação. Mostra uso real e quais telas geram dúvida.

  • Implantar: +1 a 2 dias
  • Manter: limpeza periódica
  • Bom para: provar uso na capacitação

Recomendação

Implantar a combinação A já, porque não depende de ninguém escrever e cobre o sistema inteiro. Escolher B ou C só quando houver alguém para escrever textos: B se forem poucas telas e o deploy for simples; C se forem muitas telas ou se os textos forem ajustados com frequência, como durante o treinamento. Os dois usam o mesmo formato de arquivo: dá para começar em B e migrar para C sem reescrever nada.

1 · Base automática

Obrigatório. Ninguém precisa escrever nada.

Baixar kit 1 · base
Implantar: ½ a 1 diaManter: nenhuma rotinaEscrita: nenhuma

O que fica pronto

Me guie: campos obrigatórios

Percorre os campos com *, na ordem da tela, e só avança depois de preenchido. Termina no botão final.

Me guie: todos os campos

Idem, com os opcionais marcados como opcionais e os campos preenchidos pelo sistema para conferir.

Manual desta tela

Grupos, campos, tipo, obrigatoriedade e botões, montado no clique. Imprime ou salva em PDF.

O guia lê a tela no momento do clique: campo novo, removido ou escondido já aparece certo, sem manutenção.

Passo a passo

    Descompacte o kit 1 e copie a pasta guia-coplan. No teste do Tributário (GeneXus 16, Java): /tributario/static/guia-coplan/.

    ├── driver.css
    └── DRIVER-LICENSE.txt

  2. Incluir os scripts na Master Page

    Ajuste o caminho se for outro e cole no Event Start da Master Page. A ordem importa: Driver.js, configuração, motor.

    Master Page · Event Start master-page-start.gx

  3. Gerar e conferir o botão

    Abra qualquer tela com campos.

    O botão ? aparece no canto inferior direito.

  4. Conferir o passo a passo automático

    Clique em Me guie: campos obrigatórios.

    O guia aponta os campos com * e só avança depois de preenchidos.

  5. Conferir o manual automático

    Clique em Manual desta tela.

    Aparecem os grupos, campos e botões da tela, sem itens do menu do sistema.

  6. Limitar a área que o guia lê

    Se o manual listar campos do menu ou do cabeçalho, preencha manualRaiz com o id da área de conteúdo da Master Page e gere de novo.

    guia-config.js Kit 1 · base 
    /* Guia Coplan v1.2 · configuração BASE (automática, ninguém precisa escrever nada).
   Carregar ANTES do guia-coplan.js. As opções de escrita (pasta ou tabela) só mudam roteirosUrl. */
window.GUIA_COPLAN_CONFIG = {
  // Passo a passo automático: gerado da própria tela (campos obrigatórios ou todos os campos).
  roteiroAuto: true,
  // Manual automático: montado na hora, lendo a tela (e os roteiros escritos, se houver).
  manualAuto: true,
  // Área da página que o guia lê. Indique o conteúdo da Master Page para não listar o menu e o
  // cabeçalho do sistema (ex.: '#MAINFORM' ou o id do content placeholder). null = página toda.
  manualRaiz: null,

  // Roteiros escritos: NENHUM na base. As opções 2 (pasta) e 3 (tabela) preenchem esta linha.
  roteirosUrl: [],

  // Manual escrito externo (opcional, só se já existir um). Se preenchido, o menu mostra "Manual completo".
  manualUrl: null,

  autor: false,          // true só em desenvolvimento/homologação: mostra "Criar roteiro desta tela"
  montarBotaoEm: null,   // seletor para pôr o botão "?" no cabeçalho; null = botão flutuante
  retomarMinutos: 2,     // se a tela recarregar (postback) nesse prazo, o passo a passo continua
  debug: false
};

  7. Conferir os nomes dos campos

    No console (F12): GuiaCoplan.lerTela(). Campo sem nome significa que o rótulo não está ligado ao campo no HTML; o guia tenta label, aria-label, title, a célula ao lado e o placeholder.

  8. Repetir em mais duas telas

    Uma com Select2 e lupa, outra com grid. Em produção, mantenha autor: false e debug: false.

  1. Trocar a configuração

    Copie o guia-config.js do kit 2 por cima do da base. Ajuste roteirosUrl para o caminho real da pasta (começando com /) e mantenha o manualRaiz que você definiu.

    guia-config.js Kit 2 · pasta 
    /* Guia Coplan v1.2 · configuração com a OPÇÃO 2 (roteiros e ajuda escritos em arquivos .json).

  roteiroAuto: true,
  manualAuto: true,
  manualRaiz: null,     // conteúdo da Master Page (ver LEIA-ME da base)

  // O guia busca <pasta><nome da tela>.json. Tela sem arquivo continua com o automático.

  manualUrl: null,
  autor: false,
  montarBotaoEm: null,
  retomarMinutos: 2,
  debug: false

  2. Copiar a pasta de roteiros

    Copie roteiros/ para dentro de guia-coplan/ no servidor. Ela traz o roteiro real da NFS-e e o _modelo.json.

    Abra a emissão de NFS-e.

  5. Publicar

    Coloque o arquivo em guia-coplan/roteiros/ no servidor (o nome já sai igual ao da tela) e recarregue a tela.

  6. Manter

    Depois de cada atualização do sistema, abra as telas com roteiro escrito e rode GuiaCoplan.verificar(). encontrado: false significa campo com ID novo: corrigir pelo modo autor.

Passo a passo

  1. Criar a Transaction GuiaRoteiro

    Um registro por tela. Aplique o Work With que a KB já usa e restrinja o cadastro a administradores.

    AtributoTipoUso
    GuiaRoteiroTela (chave)Character(100)Nome da tela, em minúsculas
    GuiaRoteiroTituloVarChar(200)Descrição na lista do cadastro
    GuiaRoteiroJsonLongVarCharRoteiros e bloco "ajuda", igual ao arquivo .json
    GuiaRoteiroAtivoBooleanDesliga sem apagar
    GuiaRoteiroAlteradoPor / AlteradoEmVarChar / DateTimeAuditoria

  2. Criar o Procedure GuiaRoteiroObter

    Main program = True e Call protocol = HTTP. Devolve o JSON da tela ou null.

    GuiaRoteiroObter · Source Call protocol = HTTP 
    Source
  &Tela = &HttpRequest.GetVariable('tela')
  &Tela = &Tela.Trim().ToLower()
  &Json = ''

  For each GuiaRoteiro
      Where GuiaRoteiroTela = &Tela
      Where GuiaRoteiroAtivo = True
      &Json = GuiaRoteiroJson
  Endfor

  &HttpResponse.AddHeader('Content-Type', 'application/json; charset=utf-8')
  &HttpResponse.AddHeader('Cache-Control', 'no-cache')
  If &Json.IsEmpty()
      &HttpResponse.AddString('null')
  Else
      &HttpResponse.AddString(&Json)
  EndIf

  3. Testar a URL do Procedure

    Abra no navegador com ?tela=tnota_padrao_nacional.

    Sem cadastro, volta null.

  4. Trocar a configuração

    Copie o guia-config.js do kit 3 por cima do da base, com a URL real do Procedure e {tela} no lugar do nome.

    guia-config.js Kit 3 · tabela 
    /* Guia Coplan v1.2 · configuração com a OPÇÃO 3 (roteiros e ajuda escritos em tabela do banco).
   Substitui o guia-config.js da base. Tudo o que é automático continua funcionando. */
window.GUIA_COPLAN_CONFIG = {
  roteiroAuto: true,
  manualAuto: true,
  manualRaiz: null,     // conteúdo da Master Page (ver LEIA-ME da base)

  // Tenta na ordem e usa o primeiro que responder. {tela} é trocado pelo nome da tela.

    // 1) Procedure GuiaRoteiroObter (conferir a URL real gerada pelo GeneXus)
    '/tributario/servlet/com.tributario.aguiaroteiroobter?tela={tela}',
    // 2) Pasta, opcional: útil durante a migração da opção 2 para a 3. Pode apagar esta linha.

  ],

  autor: false,

    Com debug: true, o console mostra que o roteiro veio do Procedure.

    Modo autor, Testar, Copiar JSON, acrescentar o bloco "ajuda" se quiser, colar no cadastro e GuiaCoplan.recarregar(). Um JSON quebrado deixa a tela só com o automático.

    Igual à opção pasta: GuiaCoplan.verificar() nas telas escritas depois de cada atualização. O histórico de quem alterou fica na tabela.

     - texto JSON, inclusive JSON dentro de texto (comum quando vem de LongVarChar), com ou sem BOM
     - envelope com uma única propriedade, ex.: { "Json": "..." } (retorno típico de REST GeneXus)
     - "null", vazio ou 404 = tela sem roteiro */
  function interpretar(r, nivel) {
    nivel = nivel || 0;
    if (r == null || nivel > 4) return null;
    if (typeof r === 'string') {
      var t = r.replace(/^﻿/, '').trim();
      if (!t || t === 'null') return null;
      try { return interpretar(JSON.parse(t), nivel + 1); } catch (e) { log('resposta não é JSON', e); return null; }
    }
    if (ehLista(r)) {
      var lista = [];
      for (var i = 0; i < r.length; i++) { var x = interpretar(r[i], nivel + 1); if (x) lista = lista.concat(x); }
      return lista.length ? lista : null;
    }
    if (typeof r === 'object') {
      if (r.passos && r.passos.length) { var um = [r]; if (r.ajuda) um.ajuda = r.ajuda; return um; }
      if (ehLista(r.roteiros)) { var v = interpretar(r.roteiros, nivel + 1); if (v && r.ajuda) v.ajuda = r.ajuda; return v; }
      var chaves = Object.keys(r);
      if (chaves.length === 1) return interpretar(r[chaves[0]], nivel + 1);
    }
    return null;
  }

  function urlDoRoteiro(base, tela) {
    var t = encodeURIComponent(tela);
    return base.indexOf('{tela}') >= 0 ? base.replace(/\{tela\}/g, t) : base + t + '.json';
  }

  function buscar(url) {
    return fetch(url, { cache: 'no-cache', credentials: 'same-origin' })
      .then(function (r) { return r.ok ? r.text() : null; })
      .then(function (txt) { return interpretar(txt); })
      .catch(function (e) { log('falha ao buscar', url, e); return null; });
  }

  function carregarRoteiros(tela) {
    if (CFG.roteiros) return Promise.resolve(interpretar(CFG.roteiros[tela]));
    var fontes = [].concat(CFG.roteirosUrl || []);
    var i = 0;
    function proxima() {
      if (i >= fontes.length) return Promise.resolve(null);
      var url = urlDoRoteiro(fontes[i++], tela);
      return buscar(url).then(function (r) { if (r) { log('roteiro de', url); return r; } return proxima(); });
    }
    return proxima();
  }

  /* Texto do balão: tudo é tratado como texto puro, exceto estas marcações simples.
     Evita que um roteiro cadastrado no banco injete script na tela de todos os usuários. */
  var TAGS_LIVRES = /&lt;(\/?)(b|strong|i|em|u|br)\s*\/?&gt;/gi;
  function textoSeguro(s) {
    if (s == null) return '';
    return String(s)
      .replace(/&/g, '&amp;').replace(/</g, '&lt;').replace(/>/g, '&gt;')
      .replace(/"/g, '&quot;').replace(/'/g, '&#39;')
      .replace(TAGS_LIVRES, function (m, barra, tag) { return '<' + barra + tag.toLowerCase() + '>'; });
  }

  /* ---------- condição de "esperar" ---------- */
  // tipos: "clique" | "preenchido" | "marcado"
  function condicaoAtendida(p, i) {
    var e = p.esperar;
    if (!e) return true;
    if (e.tipo === 'clique') return !!passoOk[i];
    var itens = qa(seletor(e.alvo || p.alvo));
    for (var k = 0; k < itens.length; k++) {
      if (e.tipo === 'marcado' && itens[k].checked) return true;
      if (e.tipo === 'preenchido' && String(itens[k].value || '').trim() !== '') return true;
    }
    return false;
  }

  }

  /* Passo visível = sem alvo (mensagem central) ou alvo presente e realmente exibido na tela. */
  function passoVisivel(p) {
    if (!p.alvo) return true;
    var e = q(seletor(p.alvo));
    if (!e) return false;
    if (!(e.offsetWidth || e.offsetHeight || e.getClientRects().length)) return false;
    var cs = w.getComputedStyle(e);
    return cs.visibility !== 'hidden' && cs.display !== 'none';
  }

  // Índice do próximo (dir=1) ou anterior (dir=-1) passo visível; -1 se não houver.
  function vizinhoVisivel(atual, dir) {
    var passos = roteiroAtual.passos;
    for (var k = atual + dir; k >= 0 && k < passos.length; k += dir) {
      if (passoVisivel(passos[k])) return k;
    }
    return -1;
  }

    if (!passoVisivel(roteiroAtual.passos[inicio] || {})) {

      inicio = v >= 0 ? v : 0;

  }

  /* ---------- ferramentas para o desenvolvedor ---------- */
  function seletorDe(no) {
    if (!no || no === d.body) return 'body';
    if (no.id) return '#' + (w.CSS && CSS.escape ? CSS.escape(no.id) : no.id);
    var caminho = [];
    while (no && no.nodeType === 1 && no !== d.body) {
      if (no.id) { caminho.unshift('#' + (w.CSS && CSS.escape ? CSS.escape(no.id) : no.id)); break; }
      var tag = no.tagName.toLowerCase(), pai = no.parentNode, idx = 1, irm = no;
      while ((irm = irm.previousElementSibling)) if (irm.tagName === no.tagName) idx++;
      caminho.unshift(tag + ':nth-of-type(' + idx + ')');
      no = pai;
    }
    return caminho.join(' > ');
  }

  /* Seletores para um elemento: o ID exato e, se o ID tiver prefixo de Web Component (W0003...),
     também a versão pelo fim do ID, que sobrevive à mudança de prefixo. */
  function alvoDe(no) {
    var s = seletorDe(no);
    var m = no && no.id && /^(W\d{4})+(.+)$/.exec(no.id);
    if (m) return [s, "[id$='" + m[2].replace(/'/g, "\\'") + "']"];
    m = no && no.id && /^select2-(W\d{4})+(.+)-container$/.exec(no.id);
    if (m) return [s, "[id^='select2-'][id$='" + m[2].replace(/'/g, "\\'") + "-container']"];
    return s;
  }

    var t = '';
    if (no.id) { var lb = q('label[for="' + no.id.replace(/"/g, '\\"') + '"]'); if (lb) t = lb.textContent; }
    if (!t && no.closest) { var lw = no.closest('label'); if (lw) t = lw.textContent; }
    if (!t) t = no.getAttribute('aria-label') || no.getAttribute('title') || '';
    if (!t && no.closest) { var td = no.closest('td'); var ant = td && td.previousElementSibling; if (ant && !ant.querySelector('input,select,textarea,button')) t = ant.textContent; }
    if (!t) t = no.getAttribute('placeholder') || '';
    if (!t && /^(BUTTON|A)$/.test(no.tagName)) t = no.textContent;
    if (!t && no.tagName === 'INPUT' && /^(button|submit)$/i.test(no.type)) t = no.value;
    return String(t).replace(/\s+/g, ' ').replace(/[:*]\s*$/, '').trim().slice(0, 80);
  }

  function roteiroDoRascunho() {
    var r = { tela: telaCarregada, titulo: rascunho.titulo || 'Roteiro', passos: [] };
    rascunho.passos.forEach(function (p) {
      var x = {};
      if (p.alvo) x.alvo = p.alvo;
      x.titulo = p.titulo || '';
      x.texto = p.texto || '';
      if (p.lado && p.lado !== 'bottom') x.lado = p.lado;
      if (p.opcional) x.opcional = true;
      if (p.esperar) x.esperar = { tipo: p.esperar, mensagem: p.mensagem || 'Execute a ação indicada para continuar.' };
      r.passos.push(x);
    });
    return r;
  }

  function visivel(e) {
    if (!e || !(e.offsetWidth || e.offsetHeight || e.getClientRects().length)) return false;
    var cs = w.getComputedStyle(e); return cs.visibility !== 'hidden' && cs.display !== 'none';
  }
  function ignorado(e) { try { return !!(CFG.manualIgnorar && e.closest(CFG.manualIgnorar)); } catch (x) { return false; } }
  function limpo(t) { return String(t || '').replace(/\s+/g, ' ').replace(/\s*[:*]\s*$/, '').trim(); }

  // passo de roteiro que aponta para o elemento (para aproveitar o texto como orientação do campo)
  function passoDoCampo(e) {
    for (var i = 0; i < roteirosTela.length; i++) {
      var ps = roteirosTela[i].passos;
      for (var k = 0; k < ps.length; k++) {
        var p = ps[k], s = seletor(p.alvo), alvo = s && q(s);
        if (alvo && (alvo === e || (alvo.contains && alvo.contains(e)))) return p;
        var es = p.esperar && seletor(p.esperar.alvo), ae = es && q(es);
        if (ae && ae === e) return p;
      }
    }
    return null;
  }

  // Lê a tela: devolve { grupos: [{ titulo, campos: [...] }], botoes: [...] }
  function lerTela() {
    var raiz = (CFG.manualRaiz && q(CFG.manualRaiz)) || d.body;
    var grupos = [], porTitulo = {}, botoes = [], vistos = [];
    function grupoDe(e) {
      var fs = e.closest && e.closest('fieldset');
      var t = fs && fs.querySelector('legend') ? limpo(fs.querySelector('legend').textContent) : 'Campos';
      if (!porTitulo[t]) { porTitulo[t] = { titulo: t, campos: [] }; grupos.push(porTitulo[t]); }
      return porTitulo[t];
    }
    [].forEach.call(raiz.querySelectorAll('input, select, textarea'), function (e) {
      var tipo = (e.type || '').toLowerCase();
      if (tipo === 'hidden' || ignorado(e)) return;
      if (/^(button|submit|reset|image)$/.test(tipo)) { if (visivel(e)) botoes.push({ nome: limpo(e.value || rotuloDe(e)), id: e.id }); return; }
      if (!visivel(e) && !(e.closest && e.closest('.select2-container'))) {
        // select escondido pelo Select2 continua valendo: o usuário vê o container
        if (!(e.tagName === 'SELECT' && e.nextElementSibling && /select2/.test(e.nextElementSibling.className || ''))) return;
      }
      if (tipo === 'radio' && e.name) { if (vistos.indexOf('radio:' + e.name) >= 0) return; vistos.push('radio:' + e.name); }
      var nome = rotuloDe(e) || e.name || e.id;
      var lb = e.id && q('label[for="' + e.id.replace(/"/g, '\\"') + '"]');
      var rotuloBruto = (lb ? lb.textContent : '') + ' ' + (e.closest && e.closest('label') ? e.closest('label').textContent : '');
      var p = passoDoCampo(e);
      var obrig = e.required || e.getAttribute('aria-required') === 'true' || /\*/.test(rotuloBruto) ||
                  /required|obrigat/i.test(e.className || '') || !!(p && p.esperar && p.esperar.tipo === 'preenchido');
      var t;
      if (e.readOnly || e.disabled) t = 'Preenchido pelo sistema';
      else if (e.tagName === 'SELECT') {
        var ops = [].filter.call(e.options, function (o) { return o.value !== ''; }).map(function (o) { return limpo(o.textContent); });
        t = 'Lista de opções' + (ops.length ? ' (' + ops.slice(0, 4).join('; ') + (ops.length > 4 ? '; ...' : '') + ')' : '');
      }
      else if (tipo === 'checkbox') t = 'Marcar se aplicável';
      else if (tipo === 'radio') t = 'Escolher uma opção';
      else if (e.tagName === 'TEXTAREA') t = 'Texto livre';
      else if (/^(date|datetime-local)$/.test(tipo)) t = 'Data';
      else if (tipo === 'email') t = 'E-mail';
      else if (/^(number)$/.test(tipo)) t = 'Número';
      else t = 'Digitação' + (e.placeholder ? ' (ex.: ' + limpo(e.placeholder) + ')' : '');
      if (e.parentNode && e.parentNode.querySelector && e.parentNode.querySelector('a.gx-image-link')) t += ', com lupa de consulta';
      grupoDe(e).campos.push({ nome: limpo(nome), tipo: t, obrigatorio: !!obrig && !(e.readOnly || e.disabled), orientacao: p ? (p.texto || '') : '', opcional: !!(p && p.opcional), id: e.id });
    });
    [].forEach.call(raiz.querySelectorAll('button, a.btn, a[role=button]'), function (e) {
      if (ignorado(e) || !visivel(e) || e.classList.contains('gx-image-link')) return;
      var nome = limpo(e.textContent || e.getAttribute('aria-label') || e.title);
      if (nome) botoes.push({ nome: nome, id: e.id });
    });
    botoes.forEach(function (b) { var p = b.id && passoDoCampo(q('#' + (w.CSS && CSS.escape ? CSS.escape(b.id) : b.id))); b.orientacao = p ? (p.texto || '') : ''; });
    return { tela: telaCarregada || telaAtual(), grupos: grupos.filter(function (g) { return g.campos.length; }), botoes: botoes };
  }

     aparecem, com o rótulo de cada um como título e um texto conforme o tipo. Campo obrigatório
     espera ser preenchido; os demais são opcionais. Se a tela tiver roteiro escrito (pasta ou
     tabela), ele aparece no menu antes do automático. */
  function itensDaTela() {
    var raiz = (CFG.manualRaiz && q(CFG.manualRaiz)) || d.body, itens = [], radios = [];
    [].forEach.call(raiz.querySelectorAll('input, select, textarea, button, a.btn, a[role=button]'), function (e) {
      if (ignorado(e)) return;
      var tipo = (e.type || '').toLowerCase();
      if (tipo === 'hidden' || (e.classList && e.classList.contains('gx-image-link'))) return;
      var botao = e.tagName === 'BUTTON' || e.tagName === 'A' || /^(button|submit|reset|image)$/.test(tipo);
      var s2 = e.tagName === 'SELECT' && e.id && q('#select2-' + (w.CSS && CSS.escape ? CSS.escape(e.id) : e.id) + '-container');
      if (!visivel(e) && !(s2 && visivel(s2))) return;
      if (tipo === 'radio' && e.name) { if (radios.indexOf(e.name) >= 0) return; radios.push(e.name); }
      var nome = limpo(botao ? (e.value && e.tagName === 'INPUT' ? e.value : e.textContent) || rotuloDe(e) : rotuloDe(e) || e.name || e.id);
      if (!nome) return;
      var lb = e.id && q('label[for="' + e.id.replace(/"/g, '\\"') + '"]');
      var bruto = (lb ? lb.textContent : '') + ' ' + (e.closest && e.closest('label') ? e.closest('label').textContent : '');
      itens.push({ el: e, s2: s2 || null, nome: nome, botao: botao, tipo: tipo,
        somenteLeitura: !botao && (e.readOnly || e.disabled),
        obrigatorio: !botao && !(e.readOnly || e.disabled) && (e.required || e.getAttribute('aria-required') === 'true' || /\*/.test(bruto) || /required|obrigat/i.test(e.className || '')),
        lupa: !!(e.parentNode && e.parentNode.querySelector && e.parentNode.querySelector('a.gx-image-link')) });
    });
    return itens;
  }

  function roteiroAutomatico(soObrigatorios) {

    itens.forEach(function (it, i) {
      if (soObrigatorios && !it.obrigatorio && !(it.botao && i > ultimoCampo)) return;
      var alvo = it.s2 ? [].concat(alvoDe(it.s2), alvoDe(it.el)) : alvoDe(it.el);
      var n = it.nome, t;
      if (it.botao) t = i > ultimoCampo ? 'Quando os dados estiverem prontos, use o botão ' + n + '.' : 'Botão ' + n + '.';
      else if (it.somenteLeitura) t = 'Preenchido pelo sistema. Confira o valor.';
      else if (it.el.tagName === 'SELECT') t = 'Selecione ' + n + ' na lista.';
      else if (it.tipo === 'checkbox') t = 'Marque esta opção se ela se aplicar.';
      else if (it.tipo === 'radio') t = 'Escolha uma das opções.';
      else if (it.el.tagName === 'TEXTAREA') t = 'Descreva: ' + n + '.';
      else t = 'Informe ' + n + '.' + (it.el.placeholder && !/opcional/i.test(it.el.placeholder) ? ' Exemplo de formato: ' + limpo(it.el.placeholder) + '.' : '');
      if (it.lupa) t += ' Se não souber o valor, use a lupa para consultar.';
      var p = { alvo: alvo, titulo: n, texto: t };
      if (it.obrigatorio && it.tipo !== 'checkbox' && it.tipo !== 'radio') p.esperar = { tipo: 'preenchido', alvo: alvoDe(it.el), mensagem: 'Campo obrigatório: informe ' + n + ' para continuar.' };
      else if (!it.botao && !it.obrigatorio) p.opcional = true;
      passos.push(p);
    });

  function carregarTela() {
    var tela = telaAtual();

  var iniciado = false;
  function iniciar(config) {
    CFG = {};
    for (var k in PADRAO) CFG[k] = PADRAO[k];
    var ext = config || w.GUIA_COPLAN_CONFIG || {};
    for (var j in ext) CFG[j] = ext[j];

    if (w.MutationObserver && !observador) {
      var t = null;
      observador = new MutationObserver(function () {
        clearTimeout(t);
        t = setTimeout(function () { if (driverObj && driverObj.isActive()) { reposicionar(); driverObj.refresh(); atualizarPopover(); } }, 150);
      });
      observador.observe(d.body, { childList: true, subtree: true });

    // Vigia a posição do campo destacado: se ela mudar (scroll, resize, CSS, campo que cresce),
    // recalcula destaque e popover. Evita o popover "perdido" no canto da tela.
    var ultimaPos = '';
    // Popup de consulta do GeneXus (lupa): é um iframe grande e visível. Enquanto ele estiver aberto,
    // o guia se pausa (overlay e popover somem, tudo fica clicável) e volta quando o popup fecha.
    function popupAberto() {
      var fr = qa('iframe');
      for (var k = 0; k < fr.length; k++) {
        if (fr[k].offsetWidth > 150 && fr[k].offsetHeight > 150) return true;
      }
      return false;
    }
    function reposicionar() {
      var ativo = !!(driverObj && driverObj.isActive());
      var pausar = ativo && popupAberto();
      var estavaPausado = d.body.classList.contains('guia-pausado');
      d.body.classList.toggle('guia-pausado', pausar);
      if (pausar) return;
      if (estavaPausado && ativo) { ultimaPos = ''; driverObj.refresh(); atualizarPopover(); }
      if (!ativo) {
        ultimaPos = '';
        // rede de segurança: se o Driver.js encerrar sem chamar onDestroyed (ex.: Esc durante a
        // animação de entrada), faz a limpeza que o onDestroyed faria
        if (driverObj) { driverObj = null; limparEstado(); if (typeof aoTerminar === 'function') { var f = aoTerminar; aoTerminar = null; f(); } }
        return;
      }
      var i = driverObj.getActiveIndex();
      var p = roteiroAtual && roteiroAtual.passos[i];
      var e = p && p.alvo ? resolverAlvo(p.alvo) : null;
      if (!e) return;
      // O GeneXus recria o controle após um evento (ex.: escolher item do dropdown):
      // o Driver.js fica com o elemento antigo, fora da página. Destaca o passo de novo.
      var destacado = driverObj.getActiveElement && driverObj.getActiveElement();
      if (destacado && destacado !== e) { ultimaPos = ''; driverObj.moveTo(i); return; }
      var r = e.getBoundingClientRect();
      var pos = [r.top, r.left, r.width, r.height, w.pageYOffset, w.pageXOffset].map(Math.round).join(',');
      if (pos !== ultimaPos) { ultimaPos = pos; driverObj.refresh(); }
    }
    setInterval(reposicionar, 250);
    w.addEventListener('resize', reposicionar);
    w.addEventListener('scroll', reposicionar, true);

    // Web User Experience "Smooth" pode trocar de tela sem recarregar a página.
    setInterval(carregarTela, 1000);
    try { if (w.localStorage && localStorage.getItem('guiaCoplanMapear') === '1') mapear(); } catch (e) {}
    carregarTela();
    try { if (w.localStorage && localStorage.getItem('guiaCoplanAutor') === '1') setTimeout(autor, 300); } catch (e) {}
  }

  w.GuiaCoplan = {
    versao: VERSAO,
    iniciar: iniciar,
    iniciarRoteiro: iniciarRoteiro,
    telaAtual: telaAtual,
    roteiros: function () { return roteirosTela.slice(); },
    mapear: mapear,
    verificar: verificar,
    testar: testar,
    recarregar: recarregar,
    autor: autor,
    manual: manual,
    roteiroAutomatico: function (o) { return JSON.parse(JSON.stringify(roteiroAutomatico(!!o))); },
    fecharManual: fecharManual,
    lerTela: lerTela,
    fecharAutor: fecharAutor
  };

  if (w.GUIA_COPLAN_CONFIG && w.GUIA_COPLAN_CONFIG.autoIniciar !== false) {
    if (d.readyState === 'loading') d.addEventListener('DOMContentLoaded', function () { iniciar(); });
    else iniciar();
  }
})(window, document);
